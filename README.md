# Python Quick Start for High School Students

Welcome to the Python Quick Start tutorial! This repository contains a one-hour introductory lesson to Python programming, designed specifically for high school students with no prior coding experience.

## How to Use This Tutorial

1.  **Start with the main tutorial file:** The core of this lesson is in the `python_quick_start.md` file. It will guide you through the basics of Python, from writing your first line of code to creating a simple number guessing game.

2.  **Refer to the code examples:** All the code snippets used in the tutorial are available in the `python_tutorial_examples/` directory. Each file is numbered to correspond with the sections in the tutorial.

3.  **Use an online interpreter:** To get started quickly without any setup, you can use an online Python interpreter like [Replit](https://replit.com/languages/python3) or [Google Colab](https://colab.research.google.com/).
